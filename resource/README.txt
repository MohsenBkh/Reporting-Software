Source folder for the application branding (bundled into the exe by ReportForge.spec).

logo.ico    window / exe icon (256x256)           - used by build_exe.bat and the app window
logo.png    application logo (1254x1254, RGBA)   - fallback icon, home page
splash.png  splash screen (812x609, RGBA)         - shown at launch until the main window opens

To change the branding replace these files (keep the same names) and run build_exe.bat again.
