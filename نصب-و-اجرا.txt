اجرای ReportForge نسخه ۱.۲.۰ («تغییرات آرنا»)
=============================================
۱) python -m pip install -r requirements.txt        (پیشنهاد: Python 3.12.4+ یا 3.13)
۲) python -m app.main      یا در ویندوز: run.bat
۳) ساخت exe:  build_exe.bat   → رفع کرش شروع + خودآزمون خودکار (RESULT : OK)
۴) بررسی سلامت exe:  dist\ReportForge.exe --smoke-test   سپس type dist\ReportForge-smoke.txt
۵) صفحات مهم:
   • Sidebar → «مطالعه مصارف سنگین» : ۶ تب (تقاضا، ایستگاه‌ها، خطوط، متقاضیان همزمان/سناریوها،
     فیدرهای همجوار (بازآرایی)، تنظیمات مطالعه) — همهٔ جدول‌ها ستون «در گزارش (On/Off)» دارند
   • «ورود داده» → پیک سال‌های گذشته با ستون «در گزارش» + جدول پیش‌بینی با همان کلید
   • شکل‌ها: هر شکل با «بخش گزارش»، «اولویت/ترتیب» و «کپشن اختصاصی» — چند شکل برای یک بخش
   • «تولید گزارش» → بخش «کنترل بارگذاری کل فیدر» با آستانه‌های ۷/۸ مگاوات از تنظیمات
   • «تنظیمات» → مطالعه و هزینه (آستانه‌های بحرانی/شدید) + بخش‌های گزارش
۶) جدول‌ها شبیه Excel: پاک‌کردن با Delete، کپی/چسباندن با Ctrl+C/V، Enter = ردیف پایین؛
   در جدول‌های گزارش فقط کپی فعال است و ویرایش داده ممکن نیست.
۷) پروژهٔ نمونه: «پروژه_نمونه_مطالعه/project.json» و گزارش نمونه در «خروجی_نمونه/»
۸) آزمون‌ها: python -m pytest tests -q --ignore=tests/test_v103_ui.py   → انتظار 185 passed
