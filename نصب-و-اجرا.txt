ReportForge (گزارش‌یار مطالعات) — نسخه ۲.۱.۰
============================================

محتوای بسته
-----------
run.bat                 اجرای برنامه از روی سورس (نصب خودکار کتابخانه‌ها در اولین اجرا)
build_exe.bat           ساخت فایل اجرایی  dist\ReportForge.exe  (+ خودآزمون خودکار)
requirements.txt        کتابخانه‌های لازم برای اجرا
requirements-build.txt  کتابخانه‌های لازم برای ساخت exe (شامل PyInstaller)
requirements-dev.txt    کتابخانه‌های لازم برای اجرای تست‌ها (شامل pytest)
ReportForge.spec        تنظیمات PyInstaller (اسپلش، آیکون، منابع همراه)
resource\               لوگو و اسپلش: logo.ico, logo.png, splash.png  (جایگزینی فایل‌ها = تغییر لوگو/اسپلش)
app\ui\fonts\           فونت‌های رابط کاربری: Vazirmatn (Regular, Medium, SemiBold, Bold)
app\                    سورس برنامه        tests\   تست‌ها        docs\   مستندات

اجرا از روی سورس
-----------------
۱) Python 3.11 یا بالاتر (پیشنهاد: 3.12.4+ یا 3.13) را با گزینهٔ «Add python.exe to PATH» نصب کنید.
۲) روی run.bat دوبار کلیک کنید. در اولین اجرا کتابخانه‌ها نصب می‌شوند (نیازمند اینترنت).
   یا دستی:  python -m pip install -r requirements.txt   سپس   python -m app.main

ساخت فایل اجرایی (exe)
-----------------------
۱) روی build_exe.bat دوبار کلیک کنید (در اولین اجرا PyInstaller و کتابخانه‌ها نصب می‌شوند).
۲) خروجی: dist\ReportForge.exe — یک فایل مستقل که لوگو، اسپلش و فونت‌ها داخل آن است.
۳) خودآزمون: dist\ReportForge.exe --smoke-test  سپس  type dist\ReportForge-smoke.txt  (انتظار: RESULT : OK)
اسپلش دقیقاً در لحظهٔ اجرای exe نمایش داده می‌شود و تا باز شدن پنجرهٔ برنامه می‌ماند.
(اسپلش لحظه‌ای نیازمند tkinter در پایتون سیستم ساخت است؛ در نبود آن، اسپلش Qt کمی دیرتر نشان داده می‌شود.)

فونت‌ها
--------
• رابط برنامه: Vazirmatn (فایل‌ها در app\ui\fonts و داخل exe بسته می‌شوند؛ مجوز SIL OFL).
• گزارش Word: فونت‌های B Nazanin / B Titr / Tahoma از «تنظیمات» انتخاب می‌شوند و باید روی
  کامپیوتری که گزارش را باز می‌کند نصب باشند (همراه برنامه نیستند).

محیط جدید (Engineering Desktop)
-------------------------------
• ریبون (File, Project, Studies, Analysis, Report, View, Help) + Project Explorer (مراحل ۱ تا ۷) + Property Inspector.
• پروژهٔ جدید: ابتدا نوع مطالعات (متقاضی سنگین / ریکلوزر / سکشنالایزر) انتخاب می‌شود.
• میان‌برها: Ctrl+N/O/S، Ctrl+R (Report Center)، F5 (اعتبارسنجی)، F6 (قواعد حفاظتی)،
  Ctrl+Shift+D (تم)، Ctrl+F1 (جمع‌کردن ریبون)، Ctrl+W (بستن تب).

تست‌ها
------
python -m pip install -r requirements-dev.txt
set QT_QPA_PLATFORM=offscreen
python -m pytest tests -q

فرایند گام‌به‌گام (Guided Flow)
--------------------------------
• نوار بالای فضای کار «گام جاری» و موارد ناتمام را نشان می‌دهد؛ هر مورد با کلیک شما را به همان صفحه و فیلد می‌برد.
• گام‌ها: ۱ اطلاعات پروژه ← ۲ ورود داده ← ۳ اعتبارسنجی ← ۴ تحلیل ← ۵ بازبینی ← ۶ پیش‌نمایش ← ۷ تولید گزارش.
  گام‌های بعدی در Project Explorer قفل (🔒) هستند و با تکمیل گام قبل باز می‌شوند.
• «ادامه با وجود نقص» گام بعد را با نقص باز می‌کند؛ تولید گزارش همیشه ممکن است و نقص‌ها در ابتدای
  گزارش با عنوان «هشدار — نقص‌های رفع‌نشده» درج می‌شود.
• الزامات هر گام بر اساس مطالعات انتخاب‌شده (متقاضی سنگین / ریکلوزر / سکشنالایزر) تعیین می‌شود.

ردیابی دقیق یافته‌ها
---------------------
• هر یافتهٔ موتور قواعد در «تنظیمات و اعتبارسنجی» هر مطالعه با ↗ مشخص است؛ دابل‌کلیک شما را به فیلد
  اصلاح می‌برد و Tooltip قاعده، منبع (سند/صفحه) و مقادیر ورودی را نشان می‌دهد.
• پیوست «ردیابی یافته‌ها» را از Report Center (انتخاب مطالعات ← بخش‌ها) روشن کنید.
• قالب‌های متن گزارش‌های حفاظتی: app\report\data\protection_templates.json (قابل ویرایش بدون تغییر کد).

دستیار هوش مصنوعی (اختیاری، نیازمند اینترنت و کلید API)
------------------------------------------------------
Report Center ← «دستیار هوش مصنوعی»  (یا Ctrl+Shift+A):
۱) ارائه‌دهنده (Claude / OpenAI / Gemini / سرویس سازگار با OpenAI) و نام مدل را وارد کنید و کلید API را «ذخیرهٔ کلید» بزنید.
   کلید داخل پروژه یا تنظیمات برنامه ذخیره نمی‌شود؛ در فایل کاربر  %USERPROFILE%\.reportforge\ai_keys.json
   یا از متغیر محیطی (ANTHROPIC_API_KEY / OPENAI_API_KEY / GEMINI_API_KEY) خوانده می‌شود.
۲) بخش‌های موردنظر و دادهٔ ارسالی (تصاویر، حذف نام اشخاص، یافته‌ها) را انتخاب کنید.
۳) «ذخیرهٔ بستهٔ ZIP» همهٔ ورودی‌ها (project.json، findings.json، sections.json، images/، task.md) را برای بایگانی یا
   بارگذاری دستی در هر ابزار هوش مصنوعی می‌سازد. «ارسال» همان محتوا را مستقیم به API می‌فرستد (پس از تأیید شما).
۴) پیشنهاد هر بخش کنار متن فعلی نمایش داده می‌شود؛ عددهایی که در داده‌ها نبوده‌اند هشدار می‌گیرند. فقط بخش‌های
   پذیرفته‌شده (و ویرایش‌شدهٔ شما) در گزارش ثبت می‌شوند (همان سازوکار «متن دستی» و با تولید مجدد حفظ می‌شوند).
نکته: خروجی هوش مصنوعی ابزار کمکی نگارش است، نه مرجع مهندسی؛ تنظیمات و اعداد را همیشه خودتان تأیید کنید.
