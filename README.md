# ReportForge — گزارش‌یار مطالعات

تولید خودکار گزارش مطالعات فنی شبکه توزیع — مطابق ساختار دفترچه‌های مطالعات
شرکت توزیع نیروی برق استان اردبیل:

- **متقاضیان سنگین (۱ مگاوات و بالاتر)** — مطابق دستورالعمل TAV111-10/00 شرکت توانیر
- **مطالعه سکشنالایزر** — ساختار گزارش فعال (جزئیات فنی متعاقباً تکمیل می‌شود)
- **مطالعه ریکلوزر** — در برنامه (به‌زودی)

## تازه در نسخه 1.1.0

- **چیدمان گزارش متقاضیان سنگین مطابق آخرین گزارش مرجع (مهر ۱۴۰۵)** — ۹ بخش:
  مقدمه ← تحلیل بارگذاری ← پیش‌بینی ← **ایستگاه‌های نزدیک** ← **خطوط نزدیک** ←
  پخش بار قبل ← پخش بار بعد ← **کنترل بارگذاری و راهکارهای تعدیل بار** ← **نتیجه‌گیری و پیشنهادات (جدول نکات تحلیلی/سناریوها)**.
- انتخاب **نوع گزارش** هنگام ساخت پروژه: متقاضیان سنگین / سکشنالایزر / ریکلوزر (به‌زودی).
- قابلیت کامل گزارش‌سازی **سکشنالایزر**: پروژه، اعتبارسنجی، پیش‌نمایش و تولید Word با ساختار اولیه (متن بخش‌ها قابل ویرایش؛ جزئیات بعدی در همین ساختار می‌نشیند).
- طبقه بارگذاری «شدیداً بحرانی»، آیتم‌های نشانه‌دار در بخش پخش بار بعد، سلول‌های چندخطی در جداول.

## تازه در نسخه 1.0.3

- رابط کاربری حرفه‌ای: Sidebar، نوار مراحل Workflow، داشبورد، Theme روشن/تاریک، آیکن‌های یکپارچه، StatusBar.
- اعتبارسنجی هوشمند (واحد، محدوده منطقی، داده ناقص) با راهنمای رفع و پرش به محل مشکل.
- تفکیک «ولتاژ مطلق» از «اثر متقاضی»؛ افزایش تلفات به‌تنهایی مبنای اقدام اصلاحی نیست.
- کنترل کیفیت پیش‌بینی (R²، Outlier، جهش/مانور، داده ناقص) با وضعیت REQUIRES_ENGINEER_REVIEW.
- بازبینی مهندس: Accept / Edit / Reject / Override / Comment با ذخیره دائمی.
- ردیابی منبع هر داده (Excel / CSV / دستی / محاسبه / PowerFactory) + پیوست‌های گزارش.
- Word بهبودیافته: «صفحه X از Y»، جلد بدون شماره، TOC، Caption Style، تکرار سرستون جدول.
- تولید گزارش در Thread پس‌زمینه با Progress؛ خطاها فارسی و بدون Traceback (Log در پوشه کاربر).

جزئیات: `CHANGELOG.md` و `TEST_REPORT.md`.

## ویژگی‌ها

- **حداقل ورودی، حداکثر تولید**: کاربر فقط اطلاعات اصلی را وارد می‌کند؛ متن، جداول، شکل‌ها، شماره‌گذاری و فهرست مطالب خودکار تولید می‌شود.
- **چارچوب گزارش مطابق آخرین گزارش مرجع**: مقدمه ← تحلیل بارگذاری ← پیش‌بینی ۵ ساله ← ایستگاه‌های نزدیک ← خطوط نزدیک ← پخش بار قبل ← پخش بار بعد ← کنترل بارگذاری و تعدیل بار ← نتیجه‌گیری و پیشنهادات.
- **موتور قواعد مهندسی (Rule Engine)** با قواعد قابل ویرایش در JSON:
  - ولتاژ: محدوده مجاز (پیش‌فرض 0.95–1.05 p.u.) و سقف تغییر ۵٪ طبق دستورالعمل اتصال مصارف سنگین
  - تشخیص «افت ولتاژ موجود ≠ ناشی از بار جدید» (منطق گزارش ناب پروتئین)
  - طبقه‌بندی بارگذاری فیدر (کم‌بار / عادی / نسبتاً پربار / پربار / بحرانی)
  - جریان نسبت به ظرفیت هدایتی و هشدار افزایش تلفات
- **کتابخانه متن فارسی** (64 متن قالب در JSON) دقیقاً با ادبیات گزارش‌های مرجع — قابل ویرایش توسط کاربر.
- **تحلیل پروفیل بار**: ورود از Excel/CSV یا Paste — پیک سالانه، تاریخ پیک، ضریب توان در پیک، نمودار P/Q.
- **پیش‌بینی ۵ ساله**: رگرسیون خطی روی پیک‌های سالانه با R²؛ اگر داده کافی نباشد **هیچ عدد ساختگی تولید نمی‌شود** (اصل NEVER INVENT ENGINEERING DATA).
- **تحلیل خودکار Before/After**: ΔI، ΔLoss، ΔV و درصدها.
- **پشتیبانی چندفیدری**: ساختار گزارش و جداول خودکار با تعداد فیدر تنظیم می‌شود.
- **مانور/بازآرایی شبکه** (اختیاری) با ثبت عدم قطعیت‌ها.
- **خروجی Word فارسی RTL**: سربرگ، پاورقی با شماره صفحه، فهرست مطالب (فیلد TOC)، جداول راست‌به‌چپ، کپشن شکل/جدول.
- **ویرایش متن توسط کارشناس**: متن هر بخش قابل ویرایش است و هنگام تولید مجدد حفظ می‌شود.
- **تولید سریع از Excel**: یک فایل قالب استاندارد → پروژه کامل → اولین نسخه گزارش در چند دقیقه.
- **Auto Save** و پرسش ذخیره هنگام بستن.

## ساختار پروژه

```
app/
├── main.py              نقطه ورود
├── core/                مدل داده، تنظیمات، محاسبات، پروفیل، پیش‌بینی، اعتبارسنجی، مدیریت پروژه
├── rules/               موتور قواعد + data/rules/*.json (قابل ویرایش)
├── report/              متن، جدول، نمودار، Word، Pipeline + data/texts/*.json (کتابخانه متن)
├── excel/               قالب استاندارد Excel + Importer
├── ui/                  صفحات PySide6 (فارسی RTL)
tests/                   تست‌های واحد + ۳ سناریوی الزامی
```

## قالب Excel استاندارد (تولید سریع)

از صفحه اصلی → «قالب Excel ورودی». شیت‌ها:

| شیت | محتوا |
|---|---|
| پروژه | اطلاعات پایه (نام متقاضی، نوع درخواست، توان‌ها، پست، امور، مانور، نوع هادی، سناریوها، ...) |
| فیدرها | نام فیدر، پست، پیک MW، سال، ضریب توان، جریان‌ها، معیار بارگذاری |
| پخش بار | نتایج قبل/بعد هر فیدر (جریان، تلفات، ولتاژها) |
| پروفیل بار | Date / Feeder / P_MW / Q_MVAR |
| پیش‌بینی | پیش‌بینی دستی (اختیاری): فیدر، سال، پیک |
| ایستگاه‌های نزدیک | (اختیاری) فاصله، ظرفیت، بارگیری ترانس‌ها، تعداد فیدر برقرار |
| خطوط نزدیک | (اختیاری) فاصله، پیک خط، افت ولتاژ قبل/بعد |

سپس صفحه اصلی → «تولید سریع از Excel».

## تست

```bat
python -m pytest tests
```

سه سناریوی الزامی سند طراحی:
1. تأمین برق جدید ۱۵۰۰ کیلووات، ۱ فیدر
2. افزایش قدرت ۱۰۰۰→۱۱۰۰ کیلووات، ۲ فیدر + مانور
3. مشکل ولتاژ موجود (قبل خارج از محدوده، بعد بدون تغییر) → تشخیص «ناشی از افزایش قدرت نیست»

## اصول طراحی

- SIMPLE FOR ENGINEER — POWERFUL UNDER THE HOOD
- هیچ Thresholdی Hard-Code نیست — همه از تنظیمات/قواعد JSON
- هیچ داده مهندسی‌ای ساخته نمی‌شود؛ داده نبود = پیام شفاف
- متن گزارش فقط از داده + قواعد تعریف‌شده تولید می‌شود
