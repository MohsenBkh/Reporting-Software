# ReportForge v2.1.0 — تغییرات نسخه قبل (اصلاحات دور دوم)

| # | اصلاح | محل اصلی |
|---|---|---|
| ۱ | تصاویر: نوع شکل و بخش‌های قابل‌انتخاب فقط متناسب با مطالعات انتخاب‌شده (پروفیل/پخش بار فقط متقاضی سنگین؛ تک‌خطی/TCC/جانمایی فقط حفاظتی) | `core/report_sections.py`، `ui/images_page.py` |
| ۲ | موتور قواعد قوی‌تر + موتور تولید متن قالب‌محور و ردیابی‌پذیر برای ریکلوزر/سکشنالایزر (قالب‌ها قابل ویرایش در JSON) | `report/protection_narrative.py`، `report/data/protection_templates.json`، `rules/recloser` |
| ۳ | ردیابی دقیق خطا: هر یافته/خطا به صفحه + فیلد اصلاح و سند/صفحهٔ منبع قاعده ارجاع دارد (کلیک ← Focus روی فیلد)؛ پیوست «ردیابی یافته‌ها» در گزارش | `rules/trace.py`، `core/validation.py`، `ui/shell/*` |
| ۴ | فرایند گام‌به‌گام (Guided Flow) بر اساس مطالعات انتخاب‌شده، قفل شدن گام‌های بعدی در Explorer، نوار راهنما، «ادامه با وجود نقص» | `core/guided_flow.py`، `ui/shell/guide_bar.py` |
| ۵ | تولید گزارش حتی با خطا (با تأیید کاربر و بخش «هشدار — نقص‌های رفع‌نشده» در ابتدای گزارش) | `ui/generate_page.py`، `report/pipeline.py` |
| ۶ | نام متقاضی دیگر در مطالعات ریکلوزر/سکشنالایزر الزامی نیست | `core/validation.py` |
| ۷ | دستیار هوش مصنوعی آنلاین: بستهٔ ZIP (داده‌ها، یافته‌ها، تصاویر، دستورالعمل) + ارسال به Claude/OpenAI/Gemini/سازگار با OpenAI + بررسی و پذیرش متن هر بخش | `app/ai/*`، `ui/shell/ai_page.py` |

تغییر مهم: گزارش «فقط سکشنالایزر» هم اکنون با Report Composer ساخته می‌شود (مولد قدیمی پنج‌بخشی دیگر استفاده نمی‌شود).
اجرا: `python -m app.main` — تست: `QT_QPA_PLATFORM=offscreen python -m pytest tests/`.
