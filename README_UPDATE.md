# ReportForge v2.2.0 — پیوند با نرم‌افزار «هماهنگی حفاظت فیدر (IDMT Coordination)»

داده‌های مطالعه ریکلوزر/سکشنالایزر فقط **یک‌بار** در ابزار IDMT وارد می‌شود؛ گزارش‌ساز تنظیمات نهایی و همه نمودارها را از همان ابزار می‌خواند:

| # | قابلیت | محل اصلی |
|---|---|---|
| ۱ | ابزار IDMT (نسخه ۰۸) همراه برنامه شد + دکمه جدید **«خروجی گزارش‌ساز»** در خود ابزار: یک فایل JSON شامل ورودی‌ها، تنظیمات نهایی فاز/زمین (ریکلوزر، سرخط، سکشنالایزرها)، توالی (Shot/Dead/Reclaim/Counter) و نمودارهای TCC فاز/زمین + توالی عملکرد + برگه A4 به‌صورت PNG | `resource/idmt_coordination.html` |
| ۲ | ریبون → Studies → گروه «هماهنگی حفاظتی (IDMT)»: **«ابزار هماهنگی IDMT»** (باز کردن در مرورگر) و **«ورود از IDMT»** (Ctrl+Shift+I) | `ui/shell/engineering_window.py` |
| ۳ | ورود بسته: تنظیمات نهایی ۵۱/۵۰/۵۱N/۵۰N ریکلوزر (TMS ضریبی → درصدی، زمان آنی → ms)، رله سرخط، سکشنالایزر (توابع + Counter + Dead line درصدی)، چرخه وصل مجدد، جریان‌های خطا/بار/فیدر/ولتاژ — بدون ورود دوباره هیچ داده تکراری؛ ورود مجدد = جایگزینی (نه تکرار) | `core/idmt_bundle.py` |
| ۴ | جایگذاری خودکار نمودارها: TCC فاز/زمین → فصل «هماهنگی حفاظتی»؛ توالی و شمارنده → فصل «سناریوی عملکرد»؛ برگه تنظیمات A4 → پیوست جدید **«برگه تنظیمات هماهنگی»** (`prot_settings_sheet`؛ فقط وقتی برگه وارد شده باشد در گزارش می‌آید) | `core/report_sections.py`، `report/composer.py` |
| ۵ | قواعد ناموفق خود IDMT هنگام ورود به مهندس هشدار داده می‌شود (هیچ مقداری بازنویسی نمی‌شود) | `core/idmt_bundle.py` |
| ۶ | **حذف تولید نمودار TCC داخلی** (دیگر لازم نیست — نمودارها از IDMT می‌آیند)؛ محاسبات IEC در `core/tcc.py` برای قواعد REC-CURVE باقی است | `report/chart_generator.py`، `report/composer.py` |
| ۷ | انواع شکل جدید: «توالی عملکرد و شمارنده (IDMT)» و «برگه تنظیمات هماهنگی (IDMT)» | `core/models.py` |

آزمون‌های جدید: `tests/test_v220_idmt_link.py` (۱۰ آزمون پیوند IDMT).
